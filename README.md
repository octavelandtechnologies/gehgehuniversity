# gehgehuniversity
This is a fun, Nigerian interactive website proudly brought to you by Octaveland Technologies, celebrating the highly viral lectures, street sense checklists, and relationship rules of Vice Chancellor VC GehGeh (Emmanuel Obruste). Take the 6-question challenge to generate your premium identity card!

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
